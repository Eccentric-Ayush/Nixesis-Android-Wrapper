# Replaceable Android artwork

Replace `icon.png` with a 1024×1024 PNG and `splash.png` with a 2732×2732 PNG.
Then run `pnpm run assets:generate` from `artifacts/nixesis` to regenerate the
Android launcher icon and splash-screen resources.

These are starter placeholders. Keep the icon artwork centered with clear space
around its edges so Android's adaptive icon mask does not crop it.
